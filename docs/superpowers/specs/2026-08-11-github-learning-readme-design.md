# GitHub Learning README Design

## Purpose

Create a beginner-friendly `README.md` for `my-first-project`. The file will introduce the repository, record GitHub learning goals, show current progress, and provide a compact command reference.

## Content

The README will contain four sections:

1. `My First Project` title and a one-sentence Chinese introduction.
2. A learning-goals list covering repositories, branches, commits, and the basic collaboration workflow.
3. A progress checklist showing repository creation, local connection, and the first design-document commit as complete, with the first push initially incomplete.
4. A command reference containing `git status`, `git add`, `git commit`, and `git push`.

## Learning Flow

The design document commit is the repository's first commit. The README implementation commit will therefore mark the first commit as complete and leave the first push unchecked. After both commits are successfully pushed to GitHub, a follow-up change will mark the push complete. This gives the learner multiple small, understandable commit cycles while keeping the progress record accurate.

## Scope and Validation

Only `README.md` is part of the implementation. The Markdown must render clearly on GitHub, contain no placeholders, and accurately reflect the repository state at the moment each commit is created.
